A make.fun entry for the **One-Line Office Joke Laugh-Off** bounty: one line
that makes office life funny — built on one real office detail, the boss who
calls the team "a family", and landing sharp: if we are family, somebody owes
me an inheritance.

## The joke

> My boss says we're a family here, so I asked HR when the will reading is.

## How it works

`main.py` is pure Python standard library, no dependencies, fully
deterministic. It writes the single joke to `/output/entry.txt` (UTF-8,
one line, inside the 1–200 character gate).

## Run

```sh
python3 main.py
cat /output/entry.txt
```
